# Créditos das imagens

Alguns cards de projeto usam imagens de terceiros, sempre com licença que permite o uso. Aqui estão as fontes.

- **Painéis de BI para a diretoria**: relatório de exemplo do Power BI, "DadosBI-exemplo3.2-powerBI.png", publicado no Wikimedia Commons sob a licença [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Recortado e redimensionado.
- **Assistente de código dentro do editor**: captura do Visual Studio Code 0.10.1, publicada no Wikimedia Commons sob a licença MIT. Recortada e redimensionada.
- **Câmeras que enxergam, seguem e medem**: fotografia "Shibuya Crossing. Tokyo." em domínio público, do Wikimedia Commons, com detecção de objetos feita por nós com o modelo YOLOv8.
- **Imagens e vídeos gerados por IA**: imagem gerada por nós com o modelo SDXL.
- **Dados públicos em escala**: captura de tela de um projeto nosso, o portfólio de Lucas Rangel.

As demais imagens dos cards são telas e gráficos de exemplo desenhados por nós, com dados fictícios.
